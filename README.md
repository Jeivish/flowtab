# FlowTab

A productivity-focused new tab replacement that removes friction from your daily workflow.

## The Problem

Default new tab pages are cluttered with news, ads, and distractions. Opening a new tab should help you focus, not pull your attention away.

## QoL Improvements

1. **Task Management** — Add, complete, and clear tasks without opening a separate app. Tasks persist in localStorage so they survive tab closes.
2. **Focus Timer** — Built-in Pomodoro timer with preset durations (5/15/25/45 min). Tracks daily sessions and total focus time. Browser notifications when a session ends.
3. **Quick Links** — Customizable link grid replaces the default bookmarks bar. Add/remove links with one click, no hunting through bookmark folders.
4. **Quick Notes** — Instant scratchpad with auto-save. Jot down a thought without opening a notes app. Saves after 500ms of inactivity.
5. **Personalization** — Customizable name greeting, 12/24h clock format, and four background themes.

## Tech Stack

- HTML5
- CSS3 (CSS custom properties, grid layout, responsive design)
- Vanilla JavaScript
- localStorage for persistence

## Running Locally

Open `index.html` in a browser. No build step or dependencies.
